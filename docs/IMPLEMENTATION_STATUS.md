# Статус реализации — 18 октября 2026

Исходники Stage 1 добавлены в существующий репозиторий Sayra. Старый полезный Sayra.cpp и native solution не удалены. Созданы sayra-core, sayra-cli и sayra-core-tests; конфиг примера, CMake presets и документация.

## Реализовано в исходниках

- Типы и контракты версии 1; intent, plan, router с кандидатами/причинами, ручная модель, local/cloud/auto/hybrid.
- Реестр Ollama tags/ps/show, пользовательские профили и отделение embedding от chat.
- Реальные HTTP-провайдеры Ollama и OpenAI-compatible, streaming/non-streaming, fragmented NDJSON/SSE, cancellation, cloud retry.
- EventBus с weak subscribers и request/session IDs, TextDelta, SourceAdded, AssistCard, terminal events.
- Пять read-only/diagnostic tools, schema validation, permissions, общие budgets и конечный agent loop.
- Регистрация проектов, whitelist/лимиты/поиск/чтение, Windows file-handle validation, защита traversal/reparse/ADS/hard-links.
- SQLite-беседы, восстановление/удаление, лимиты сообщений/байтов/количества бесед и privacy flags.
- Orchestrator, детерминированное чтение явного пути без native tools, runtime fallback до частичного ответа.
- Ollama embeddings, finite/nonzero validation, BGE-M3 1024, устойчивая cosine и CLI-демонстрация шести наборов.
- Realtime partial/final ingress, ограничение/дедупликация, on-demand/proactive gating, токен отмены устаревшего поколения, /live-demo.
- CLI-команды из задания, worker-generation и /cancel; публичные интерфейсы Knowledge/Research/Desktop.
- 28 поведенческих fake-based тестов; документы архитектуры, интеграции, роутинга, API и ручных проверок.

## Границы и оставшиеся работы

- Настоящие Web Research, RAG, Qdrant/Neo4j, индексатор и верификатор источников не реализованы: это Developer 2. Нет фиктивных замен.
- Qt/overlay, аудио, whisper/VAD/wake-word/TTS не реализованы: это Developer 3. Есть текстовая демонстрация/контракты.
- Proactive scheduler должен использовать generation_token и сериализацию/отмену в Desktop host. CLI показывает только OnDemand. Настоящая GUI-очередь доставки событий принадлежит Desktop, не ядру.
- Классификация эвристическая с опциональным компактным LLM-уточнением, не обученная система с измеренной точностью.
- Auto/Hybrid используют общий настраиваемый через профили score, без многошаговой local+cloud кооперации. Нет автоматических benchmark-оценок скорости/качества.
- Context budget оценивается консервативно в UTF-8 байтах, не точным tokenizer; большие запросы могут потребовать уменьшения файла/увеличения контекста.
- Есть ограничение цены за 1000 токенов и числа вызовов, но не бухгалтерский учёт фактического списания облака. Бюджет аккаунта задаётся у API-провайдера.
- Общая история ограничена retention; SQLite хранится без шифрования. Секреты, случайно набранные вручную, могут остаться в локальной истории до удаления.
- Детальное форматирование/UX диагностики, performance-тюнинг, расширенные edge-case security tests, полноценная проверка интеграции модулей — после первой ручной сборки и отзывов команды.

Подтверждён только описанный автономный прогон 28 тестов. Он не подтверждает реальный облачный/локальный ответ. Для дальнейших проверок используйте docs/SETUP_WINDOWS.md и docs/TEST_PLAN.md.
Без разрешённого Research-провайдера запрос актуальной информации завершается детерминированным сообщением без вызова LLM. Это предотвращает выдачу выдуманных актуальных фактов и ссылок даже при непослушном ответе модели.
